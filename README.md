# LSBU Virtual Campus Tour 🎓

An interactive, browser-based campus tour prototype developed as part of a BSc Information Technology group project at London South Bank University (LSBU).

## Overview

The Virtual Campus Tour introduces selected university spaces using immersive 360° media and interactive navigation.

## Key Features

- Interactive university campus exploration
- 360° image-based environments
- Campus location selection and navigation
- Photo and video viewing controls
- Responsive layouts for desktop and mobile browsers
- Library route experience

## Technologies

- HTML5
- CSS3
- JavaScript
- A-Frame (WebVR framework)

## Getting Started

Clone the repository and open the project folder:

```bash
git clone https://github.com/Zaheer-sketch/Virtual-Campus-Tour.git
cd Virtual-Campus-Tour/CW2
python3 -m http.server 3000
```

Visit `http://localhost:3000`.

## Project Structure

- `CW2/index.html` — Landing page
- `CW2/sites.html` — Campus location navigation
- `CW2/site1.html` to `site4.html` — Interactive scenes
- `CW2/route.html` — Library route
- `CW2/app.js` — Interactive functionality
- `CW2/styles.css` — Interface styling
- `CW2/media/` — Media assets

## Current Limitations

Some scene images and videos are not included in the repository. Additional media assets are required for all scenes and playback options to function.

## Academic Context

Developed as a university group project focused on immersive web experiences, interactive interfaces and responsive design.

This is a student project and is not an official LSBU website.
